# note-79 G5: choice

Offered (see ideas.md): A pencil (the tip sharpens and draws a candy squiggle), B dragonfly (eyes on the tip, four
see-through wings unfold, it buzzes), C sparkler (the tip lights and bursts into candy stars).

Picked B, the dragonfly. The long pointed bar already is a dragonfly's body, so the object becomes a creature that
could live there and does something lively; the big see-through wings read at a glance and suit a bright, buzzing
upper note. The pencil is a prop and the sparkler is plain sparkles.
